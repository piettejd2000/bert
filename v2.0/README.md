# BERT v1.0

## Running the App Locally

To run this app from within this folder, use the following terminal command:

```bash
streamlit run mi_results_dashboard.py
```

## Streamlit Cloud Version

Access the live app at: https://bert-v1-0.streamlit.app

Share this URL with others to run the app remotely without installation.

## Files for Development

The following files should be pulled back to the development area for exploratory changes, new development, and testing:

- `mi_results_dashboard.py` - Main dashboard application
- `mi_excellence_booster.py` - MI excellence enhancement module
- `analyze_global_dimensions_json.py` - JSON-based global dimensions analysis
- `analyze_global_dimensions_sliding_window.py` - Sliding window analysis implementation
- `requirements.txt` - Python dependencies
- `bert_handoff_DEPLOYED.md` - Deployment documentation
